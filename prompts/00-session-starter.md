# Session starter

Paste this at the start of each milestone session, with the milestone number.

> You are the coding agent for Intakefold. We are starting milestone **NN**.
>
> 1. Read `CLAUDE.md`, `PROGRESS.md`, `DECISIONS.md`, `prompts/NN-*.md` and the spec sections it names.
> 2. Check `git status`, the recent log and branches. Stop if the tree is not clean.
> 3. Re-check the versions and facts the brief names against current sources. Update `docs/RESEARCH.md`.
> 4. Pull `dev` and create the branch named in the brief. Quote it: `#` starts a shell comment.
> 5. Run the build and tests for a green baseline, and report any failure before starting.
> 6. Restate the goal, the plan as a short list of commits, and your assumptions. Then start.
>
> Work only in the brief's scope. Commit in small steps. Keep me posted during long work. At the end, run everything CI runs, chained so a failure stops the push. Update `PROGRESS.md`, `DECISIONS.md` and the `CLAUDE.md` commands, then push the branch and give the milestone report, the PR description and the compare link.
>
> Real-model runs happen only if I say so in this session.
